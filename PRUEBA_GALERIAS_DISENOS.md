# Prueba: diseños de galerías y fotografías ampliadas

Implementado el 11/11/2026. Falta tu aceptación manual.

Puedes mostrar un mismo álbum con diferentes diseños, sin volver a subir las fotos.

## 1. Elegir las fotografías

1. Entra a **Diseño web** y recarga para obtener la versión nueva.
2. Abre **Recursos → Álbumes y galerías**.
3. Elige un álbum con tres o más fotos, o pulsa **＋ Nuevo álbum**, escribe su nombre y arrastra varias imágenes PNG/JPEG.
4. Ordena las miniaturas y pulsa **Usar este álbum**.
5. La galería queda seleccionada en el lienzo. Si ya existía, también puedes seleccionarla directamente desde Estructura.

## 2. Cambiar el diseño

A la derecha abre **Propiedades → Contenido → Diseño de galería**. Prueba las tarjetas:

| Diseño | Cómo se muestra |
| --- | --- |
| Cuadrícula | Fotos alineadas y del mismo tamaño. |
| Mosaico | Una foto principal acompañada por otras más pequeñas. |
| Muro de fotos | Columnas que conservan diferentes alturas. |
| Tarjetas | Fotos con descripción y una tarjeta independiente. |
| Carrusel | Una foto a la vez, con flechas y puntos. |
| Foto destacada | Foto grande y miniaturas para elegir otra. |
| Tira panorámica | Varias fotos en una franja horizontal. |

Las mismas fotos y su orden deben mantenerse al cambiar de diseño.
En los diseños estáticos puedes ajustar **Columnas en computadora**; en celular se adaptan al espacio disponible.

## 3. Probar los efectos

1. En **Efecto al pasar el mouse**, prueba Acercamiento suave, Elevar fotografía y De blanco y negro a color.
2. Activa y desactiva **Mostrar descripciones**.
3. En Carrusel o Foto destacada, elige las transiciones Deslizar, Fundido y Zoom. Usa las flechas para comprobarlas.
4. Si activas **Pasar fotografías automáticamente**, elige el tiempo. Mientras editas permanece detenido; revisa el avance después en **Vista previa guardada**.
5. En la vista previa, el avance se pausa al interactuar, abrir una foto o salir de la zona visible. Si tu dispositivo solicita movimiento reducido, se respeta esa preferencia.

## 4. Ampliar una foto

1. Haz clic sobre una fotografía. Debe abrirse un visor que ocupa la ventana completa, incluso desde el editor.
2. Recorre las imágenes con las flechas y las miniaturas.
3. Prueba las flechas del teclado y el botón de zoom.
4. Cierra con × o Escape. Debes regresar al diseño sin perder el trabajo.
5. Abrir o recorrer fotos no debe marcar el borrador como modificado.
6. En celular revisa que la imagen se ajuste y puedas recorrerla también deslizando horizontalmente.

Para seleccionar la galería sin ampliar una foto puedes utilizar su nombre en Estructura.
Para cambiar las imágenes utiliza **Elegir o editar fotografías**.

## 5. Guardar y comparar

1. Pulsa **Guardar borrador**. Primero cancela el modal y después repite y confirma.
2. Recarga: deben conservarse el diseño, el efecto, las descripciones y el orden.
3. Abre **Vista previa guardada** y compara usando el mismo ancho de ventana.
4. La página publicada conserva la versión anterior hasta que decidas publicar. No necesitas publicar para esta prueba.

Verificación técnica: 1,111 pruebas Java, 177 JavaScript y 9 pruebas de integración/unidad en PostgreSQL aislado aprobadas. Revisión de navegador con datos ficticios en escritorio y celular de 390 px. Sin nuevas tablas ni cambios a los permisos.
